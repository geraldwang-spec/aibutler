1. 單選 Python 中哪個值是整數？
A. 12
B. "12"
C. 12.5
D. True
答案：A
解析：12 是 int；引號內是字串。

2. 單選 type("hello") 的結果代表哪種型別？
A. 整數
B. 字串
C. 浮點數
D. 串列
答案：B
解析：雙引號包住的文字屬於 str。

3. 單選 x = 5，x > 3 的結果是什麼？
A. False
B. None
C. True
D. 3
答案：C
解析：5 大於 3，因此結果為 True。

4. 單選 Python 使用哪個關鍵字開始條件判斷？
A. for
B. def
C. return
D. if
答案：D
解析：if 用來依條件選擇執行分支。

5. 單選 len([10, 20, 30]) 的結果是什麼？
A. 3
B. 2
C. 30
D. 60
答案：A
解析：串列中有三個元素。

6. 單選 list(range(3)) 的結果是什麼？
A. [1, 2, 3]
B. [0, 1, 2]
C. [0, 1, 2, 3]
D. [3]
答案：B
解析：range 從 0 開始，不包含終點 3。

7. 單選 查詢資料表內容使用哪個 SQL 指令？
A. DELETE
B. INSERT
C. SELECT
D. UPDATE
答案：C
解析：SELECT 用來讀取查詢資料。

8. 單選 要篩選 age 大於 18 的資料，應使用哪個子句？
A. ORDER BY age
B. GROUP BY age
C. LIMIT 18
D. WHERE age > 18
答案：D
解析：WHERE 用來篩選符合條件的資料列。

9. 單選 PRIMARY KEY 的主要用途是什麼？
A. 唯一識別資料列
B. 加密所有欄位
C. 自動排序文字
D. 刪除重複資料表
答案：A
解析：主鍵用來唯一識別資料列，不能為 NULL。

10. 單選 FOREIGN KEY 主要維護什麼？
A. 字串長度
B. 資料表間的參照完整性
C. 查詢排序
D. 欄位顏色
答案：B
解析：外鍵將資料列與另一個資料表的鍵建立關聯。

11. 單選 ORDER BY score DESC 會如何排序？
A. 分數由低到高
B. 隨機排序
C. 分數由高到低
D. 只留下最高分
答案：C
解析：DESC 表示降冪排序。

12. 單選 要取消尚未提交的交易變更，使用哪個指令？
A. COMMIT
B. SELECT
C. CREATE TABLE
D. ROLLBACK
答案：D
解析：ROLLBACK 回復尚未提交的交易。
