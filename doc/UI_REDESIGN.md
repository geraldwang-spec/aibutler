# 學習工作室介面

> 同學負責的體育功能都在 `body` 內。全站外層統一紫色側欄，右側採同源 iframe 獨立載入；BODY 內容保留原本 CSS，不載入紫色 product 樣式。沒有修改 `body/`、`templates/body/`、`static/body/` 或運動資料。

2026-10-05：參考 Linear 的側欄與資訊密度、Notion Calendar 的月曆布局、Coursera 的課程卡片，採淺灰底、白色內容區與紫色主要操作。

視覺補強：`workspace-decor.css` 加入淡紫、米色與淺綠底色、卡片邊框和柔和陰影。頁首、首頁迎賓區、統計卡、教材與課程封面使用本機 SVG 小插圖（書本、學習桌、進度），不增加 CDN 或模型依賴。只對 `.product-ui` 生效，BODY 內容不載入此樣式；內容文字、表單及路由保留。

此次調整模板、樣式與導覽容器，沒有調整資料庫、模型、判分或 API 行為。

- 新全站框架：分組導覽、目前頁面標示、麵包屑與帳號區；保留進階功能及所有資料管理入口。
- 首頁：統計摘要、主要月曆、今日任務、工具卡片。月曆每一天將細項合併為紫色「讀書安排」與綠色「運動安排」，各顯示總項目數；點擊以對話框查看細項與原計畫連結，避免日期格塞滿任務。原始計畫與狀態不變。
- 主頁摘要卡參考學習計畫呈現預計分鐘、項目数、完成數與查看安排按鈕；展開後沿用管理安排、記錄已閱讀、系統測驗等原有入口。時間只顯示真實的目標時長，沒有虛構開始時段，也不新增查詢或更動排程。
- 學習計畫月曆每天只顯示一張淡紫摘要卡，以預計分鐘為主要資訊；細項、測驗門檻、成績與原有按鈕移入點擊後的對話框。減少同時呈現的任務數，不減少課程內容，也不改進度或判分規則。
- 兩種月曆統一週一至週日、預設本月及僅顯示當月任務，目標／月份切換與相互連結保留月份。主頁預設合計所有學習目標及手動計畫，增加目標篩選：選定目標後讀書區只採該目標的 learning_tasks，運動計畫保留；细項顯示目標名稱，避免把全部合計與單一目標誤認為同一範圍。不合併、刪除或重排原有任務。
- 時長：學習任務直接讀取 target_minutes；手動計畫換算分鐘／小時／秒；運動安排優先使用本項設定，缺少時長時讀取採用中的 workout_templates.minutes_per_session，再回退個人設定 minutes_per_session。細項標明時間來源，不更動 BODY 檔案或把實際訓練耗時當成規劃時長。2026-10-06 唯讀診斷確認學習任務皆有 20–90 分鐘，5000 程式卻仍執行 2026-10-05 啟動的舊版本，導致熱更新模板讀不到新加入的時長資訊。
- 動態恢復：不綁定星期。依累積 120 分鐘、連續數天的學習負荷或驗收後安排休息；視驗收位置及負荷安排約 10 分鐘輕量回顧，原有測驗日期保留。休息／輕量為綠色，學習紫色，運動藍色（僅主頁呈現，不改 BODY UI）。休息不用打卡或補進度，可自選散步／伸展約 10 分鐘，不建立運動任務或訓練紀錄。已撤回先前固定星期安排；只調整 admin123 尚未開始、沒有測驗嘗試的未來任務，更新前保存 instance/schedule_before_recovery_*.json 備份，其他帳號不變。
- 題庫：收合新增表單，保留全部欄位與編輯／刪除；長題幹摘要與可展開解析。
- 教材：卡片書架與可展開上傳區；沒有新增不存在的檔案瀏覽功能。
- 微課程：課程卡片優先顯示，建立補強課程移至展開區。
- 對話：歷史清單、置中訊息、可捲動對話區及固定在內容底部的輸入區。
- 登入：沿用相同配色與表單樣式。
- 運動 `/body` 頁使用同一個外層側欄，右側保留原版內容、專屬樣式與程式。切換體育分頁時會同步目前入口標示。

`workspace_ui.py` 只攔截已登入使用者的已知 HTML 頁面 GET，先呈現外殼，原有頁面處理函式於右側載入時執行一次。以瀏覽器 `Sec-Fetch-Dest: iframe` 辨識內容頁，表單、重新導向、原有腳本仍在各自頁面內正常執行。登入、登出、API、下載與 POST 不被此攔截器修改。

`templates/live_base.html` 對內容頁選用 `workspace_pane.html`，外層為 `product_base.html`。`workspace-navigation.js` 管理側欄切換、頁名、網址與返回；`workspace-pane.js` 同步內容頁內連結及 BODY 原有 History API 的狀態。右側文件獨立，切頁會自然清除舊頁腳本與計時器。原始 `live_base_legacy.html` 保留作為參考。

已移除側欄重複的概念、AI 出題、弱項與分析入口；主要管理功能直接顯示，其他資料管理保留展開入口。

先前曾以示例資料產生首頁、教材、課程與對話純靜態預覽。本次依使用者要求不執行功能測試，只檢查程式與模板語法、入口對應及 BODY 檔案差異。新導覽註冊於 app 啟動階段，正式系統必須重新啟動一次。

預覽工具：`python tools/render_ui_preview.py`，輸出 `instance/ui_preview/`。預覽資料為排版示例，操作連結及表單不連正式功能。正式系統需重新啟動後看實際資料，CSS 如有快取可使用 Ctrl+F5。


### 科目與章節收納工作區

- 合併科目／章節入口，以科目資料夾搭配主章節、子章節目錄管理。沿用原有資料與權限，不自動重建或搬動內容。
- 支援搜尋、同層排序、拖曳排序／重新分類／移回最上層、批次貼上章節清單，並略過同層重複名稱。
- 跨科目拖曳限未使用且無上下層關係的空章節；已有考題、教材、概念或學習紀錄時保留原科目，避免科目關聯及考試歷史失真。
- 各章節可查看固定題庫；以此範圍出卷會預選該章節與所有子章節，科目出卷則預選整個科目。沿用普通隨機出題，使用者確認題數及題型後才建立考卷。
- 使用現有 chapters.parent_chapter_id，無新增資料表。CSRF、帳號資料隔離、唯讀備援及關聯資料刪除限制維持有效。BODY 檔案未修改。
- 依使用者要求只檢查語法，不執行功能測試。
### 統一介面整理方向

- 範圍先於內容：目前目標／科目要清楚，選中狀態使用整張底色、完整外框與標記。
- 摘要先於細節：月曆以每日總時間與大項呈現；里程碑以百分比與圖標呈現；錯題、草稿先看摘要再展開內容與操作。
- 主操作維持可見，次要說明與歷史紀錄使用有明確標題及數量的展開區；錯誤與必要設定提示保留可见。
- 統一內容寬度、卡片間距、篩選區與題庫分頁，保留柔和紫色主題及既有休息／運動顏色。
- 每個分類與折疊區都沿用原本資料、表單欄位、提交路徑與判定規則。折疊不清空或停用已選項目。
- 共用整理樣式與摘要腳本僅用於學習頁；BODY 文件、樣式、功能與資料維持原狀。
