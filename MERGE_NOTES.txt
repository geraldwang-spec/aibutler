AI Butler 整合版（body / TYE 分離）

整合原則：
1. body/ 完整保留「同學.zip」內容，不把 TYE 或 Personal AI 程式搬進 body。
2. TYE/ 完整保留「我的.zip」內容，不把 body 程式搬進 TYE。
3. 模組整合主要由 app.py 負責：建立共用 Flask app 後，再註冊 TYE 與 Personal AI；body 仍維持自己的 Blueprint/目錄結構。
4. templates/body 與 static/body 保留同學版本，供 body 模組自行使用。
5. 資料庫正式連線統一採用同學 .env 的 MariaDB 設定（DB_TYPE=mariadb、DB_HOST/PORT/USER/PASSWORD/NAME）。
6. storage.py 使用 MariaDB adapter，既有 SQLite 風格 ? placeholder 會轉成 PyMySQL %s；SQLite 僅留給測試 fallback，不作正式資料來源。
7. schema_mariadb.sql 已補上 Personal AI / adaptive planner / micro-course 所需資料表，讓新增功能也共用同一個 MariaDB。
8. MariaDB 下 RAG 先使用文字檢索 fallback；原本 PostgreSQL pgvector 專用 SQL 不會執行。

模組責任：
- body/：同學維護
- TYE/：筠翔維護
- personal_ai/：筠翔個人 AI / RAG / 學習排程功能
- app.py：模組組裝入口，後續整合優先在這裡註冊，不直接改 body/TYE 內部內容

首次使用：
- pip install -r requirements.txt
- 若遠端 MariaDB 尚未建齊資料表，再執行 python init_db.py
- 平常啟動 python app.py
