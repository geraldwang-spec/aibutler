通用題庫匯入

支援 PDF、Word、Excel、CSV。所有格式都先解析成題目預覽，確認後才寫入系統。

推薦：使用「概念型匯入」。系統會用 Embedding + Concept Classifier 判斷題目真正考的知識點；相同概念不會一直堆進固定題庫，原題只保留成來源樣本，之後由 LLM 依 Concept 重新設計新題。

下載 CSV / Excel 題庫範本

概念型：題目 → bge-m3 找語意近鄰 → Classifier LLM 歸入 Concept / Skill → 保留來源樣本。模擬題由 Generator LLM 重新設計。

注意：「快速解析」只代表不用 LLM 拆 PDF 題目；若選概念型匯入，仍會執行 Concept Classifier。Concept 分類目前預設使用本機 qwen3.5:4b；高成本生成任務可交由 Groq。
